# Contributing to AgentLens

Check [docs/ROADMAP.md](docs/ROADMAP.md) for the implemented boundary and planned milestones. Read the [engineering principles](docs/PRINCIPLES.md) and [quality gates](docs/QUALITY_GATES.md) before changing shared contracts or release behavior.

## Development loop

1. Update the relevant contract or ADR when a project-wide rule changes.
2. Make the smallest change that satisfies the contract.
3. Add or update a focused check for changed behavior.
4. Run the backend and, when affected, dashboard checks in the README.
5. Record evidence and limitations; do not invent benchmark results or certification claims.

Milestones M14–M30 in the roadmap are planned. Keep implementation and public documentation aligned with what is present and verified in the repository.
