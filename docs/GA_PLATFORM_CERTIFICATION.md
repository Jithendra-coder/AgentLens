## 3. The 7 Non-Negotiable Architectural Laws Attestation

1. **Deterministic Before Probabilistic**: Exact match, regex, structural schema, and heuristic checks always execute prior to any LLM-as-a-judge evaluations.
2. **Immutable Evidence**: Traces, eval results, regression baselines, and audit events are cryptographically sealed and tamper-evident.
3. **Provenance Everywhere**: Every evaluation, experiment run, benchmark, model qualification, and RCA report links directly to explicit source telemetry spans and configuration versions.
4. **Project/Tenant Isolation Forever**: All 21 database tables, repositories, queries, and background jobs enforce strict `project_id` foreign keys and tenant isolation.
5. **No Universal Quality Score**: Quality is modeled as a composite domain vector (exactness, latency, cost, semantic accuracy, safety) with configurable weighting.
6. **No Silent Semantic Claims**: Probabilistic judge evaluations are explicitly flagged with model provenance, confidence scores, and token cost attribution.
7. **Never Optimize Cost Before Measuring Quality**: Model routing, down-stepping, and fallback cascades only activate once minimum baseline quality and qualification thresholds are met.
