# ADR-033 - Server-Side Dashboard Credential Boundary

Status: Accepted for M8.

## Decision

The dashboard uses a same-origin Next.js server-side BFF. The BFF reads
`AGENTLENS_API_BASE_URL` and `AGENTLENS_PROJECT_API_KEY` from server
environment, forwards an allowlisted GET path, and never serializes the key or
a browser-selected project ID. FastAPI remains the authentication and tenant
isolation authority.

## Consequences

The browser cannot forge project scope or call the backend without the BFF
boundary. The dashboard is intentionally a project deployment, not an account
or multi-tenant control plane.
