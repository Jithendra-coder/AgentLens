# ADR-034 - Server-Side Analytics Aggregation

Status: Accepted for M8.

## Decision

Overview statistics, PostgreSQL percentiles, server-controlled time buckets,
evaluation counts, finding counts, and runtime summaries are computed behind
the analytics repository/service boundary. Routes serialize typed results only;
the browser never aggregates paginated trace or result pages.

## Consequences

Analytics has one bounded project/time predicate and uses PostgreSQL full
population percentile functions. Query latency is governed by the existing
database statement timeout and explicit result limits.
