# ADR-035 - Provenance-Safe Semantic Analytics

Status: Accepted for M8.

## Decision

Evaluation analytics groups keep evaluator name/version, evaluation mode,
normalized configuration fingerprint, judge profile, provider, model, and
prompt version. A group is never silently combined across those dimensions;
missing judge provenance represents deterministic evaluation rather than a
wildcard.

## Consequences

The dashboard shows comparable counts without implying that results from
different semantic programs are interchangeable. A future comparison policy
must be explicit and versioned.
