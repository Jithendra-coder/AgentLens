# ADR-036 - Read-Only Dashboard Runtime

Status: Accepted for M8.

## Decision

The dashboard exposes runtime state and safe failure metadata only. It has no
retry, cancel, replay, delete, pause, worker-control, or other mutating
operation. Worker heartbeat is reported as unavailable until a durable
heartbeat source exists; Redis degradation is observational.

## Consequences

Operators can inspect queued/running/retry/dead-letter state and infrastructure
readiness without expanding the dashboard into an operational control plane.
