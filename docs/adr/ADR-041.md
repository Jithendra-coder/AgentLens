# ADR-041 — Side-Effect-Safe Replay Policy

## Decision

Replay allows `read_only` and `sandbox` targets by default and rejects
`side_effectful` targets. M9 does not expose an operator override through the
tenant API.

## Rationale

Replaying historical cancellation, payment, email, or database-write inputs
against production would be unsafe and cannot be made harmless by a UI label.
